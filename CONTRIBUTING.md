# Contributing to IsItFree?

Thanks for helping make the software license directory more useful and accurate.

## Ways to contribute

- Suggest software that is missing from the directory.
- Report outdated or incorrect license and pricing information.
- Improve the website, accessibility, search, data quality, or documentation.
- Fix bugs or propose a focused enhancement.

## Before you start

Search existing issues and the directory to avoid duplicate reports. For license-related changes, prioritize the software publisher's official licensing, pricing, FAQ, or documentation page. Community pages can provide context, but official sources should be preferred.

## Reporting a license correction

Please include:
- The software name and the current entry, if applicable.
- What is incorrect or outdated.
- The official source URL that supports the correction.
- The date you checked the source, if relevant.

Do not guess a license category. If the publisher's terms are ambiguous, explain the ambiguity and ask for review.

## Code changes

1. Fork the repository and create a focused branch.
2. Make the smallest coherent change that addresses the issue.
3. Follow the existing HTML, JavaScript, CSV, and workflow conventions.
4. Test the affected behavior locally and check for broken links, malformed data, and console errors.
5. Open a pull request with a clear summary, reason for the change, and testing notes.

Do not commit credentials, API tokens, private information, or generated files unrelated to your change. Never place real access tokens in examples or tests.

## Software directory data

When editing directory data, preserve the existing CSV column names and format. Avoid duplicate software entries; keep names and official URLs consistent. Describe licensing based on the publisher's terms, not assumptions about a free trial or limited plan.

## Pull request review

Be prepared to answer questions or revise the change. Small pull requests with evidence and a focused scope are easier to review. Not every suggestion or change can be accepted.

## Questions
